# Resetar Trial do Cursor AI

Uma ferramenta web para auxiliar no processo de reset do período de teste do Cursor AI.

## 🔗 Acesso Rápido

Acesse a ferramenta diretamente através deste link:
[Resetar Trial do Cursor AI](https://htmlpreview.github.io/?https://github.com/suportefloripa/cursorai-renew/blob/30518747c58b9aeb49a841918ecc9dad6a949db0/index.html)

## ℹ️ Sobre o Projeto

Esta ferramenta foi desenvolvida para fins educacionais e de teste, oferecendo:
- Geração de novas chaves para teste
- Instruções detalhadas para Windows, MacOS e Linux
- Automação via PowerShell para Windows
- Dicas para evitar problemas comuns

## ⚠️ Aviso Legal

Este projeto é disponibilizado apenas para fins educacionais e de teste. O uso é de total responsabilidade do usuário. Recomendamos sempre utilizar software original e devidamente licenciado.

## 🛠️ Funcionalidades

- Gerador de chaves UUID
- Instruções passo a passo para cada sistema operacional
- Script de automação para Windows
- Dicas para desabilitar atualizações automáticas
- Soluções para problemas comuns (MAC Address Warning)
