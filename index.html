Dicas Adicionais

                        
                        
                        

                            
Como Desabilitar Atualizações Automáticas

                            
Para evitar atualizações automáticas, adicione estas configurações ao arquivo settings.json:

                            

                                
{
    "update.mode": "none",
    "update.showReleaseNotes": false,
    "update.enableWindowsBackgroundUpdates": false
}

                                
                            

                        


                        
                        

                            
Aviso sobre MAC Address

                            

                                
Se você receber o aviso "MAC Address Modification Warning", adicione estas configurações ao arquivo settings.json:

                                

                                    
{
    "security.workspace.trust.enabled": false,
    "security.workspace.trust.startupPrompt": "never",
    "security.workspace.trust.banner": "never",
    "security.workspace.trust.emptyWindow": false,
    "telemetry.telemetryLevel": "off"
}

                                    
                                

                                

                                    Importante: Estas configurações ajudam a evitar avisos de segurança relacionados ao MAC Address, mas use por sua conta e risco.
                                

                            

                        


                        
                        

                            
Automação via PowerShell (Windows)

                            

                                
Para executar todo o processo automaticamente no Windows, abra o PowerShell como administrador e execute o seguinte comando:

                                

                                    
irm https://github.com/suportefloripa/cursorai-renew/raw/main/cursor_win_id_modifier_pt-br.ps1 | iex

                                    
                                

                                

                                    
Observação: Este comando irá:

                                    
    
                                        
  • Desinstalar o Cursor automaticamente
    • 
                                        
  • Remover todas as pastas necessárias
    • 
                                        
  • Instalar a versão correta
    • 
                                        
  • Configurar as chaves necessárias
    •
